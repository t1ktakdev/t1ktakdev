## Featured projects

| Project | What it does |
| --- | --- |
| [**ForgeBridge**](https://github.com/t1ktakdev/ForgeBridge) | Local, permissioned MCP agent for authorized developer workstations. Semantic project, filesystem, Git, terminal, jobs, browser, audit, approvals, and Secure MCP Tunnel workflows. [npm](https://www.npmjs.com/package/forgebridge) |
| [**niri-zones**](https://github.com/t1ktakdev/niri-zones) | FancyZones-style zone manager for Niri with a native Wayland overlay, keyboard/mouse selection, restore state, and Niri IPC integration. [v0.1.0](https://github.com/t1ktakdev/niri-zones/releases/tag/v0.1.0) |
| [**niri-pip**](https://github.com/t1ktakdev/niri-pip) | Picture-in-Picture and floating-window control for the Niri Wayland compositor. |
| [**RouteWitness**](https://github.com/t1ktakdev/RouteWitness) | Local-first network incident recorder for intermittent connectivity failures. Captures bounded evidence before, during, and after an incident and produces offline reports. [v0.1.0](https://github.com/t1ktakdev/RouteWitness/releases/tag/v0.1.0) |
| [**ReproShot**](https://github.com/t1ktakdev/ReproShot) | CLI that turns a failing command into a local bug-report bundle with logs, Git state, runtime metadata, reproduction helpers, and secret redaction. [npm](https://www.npmjs.com/package/reproshot) |
| [**ReproDeck**](https://github.com/t1ktakdev/ReproDeck) | Desktop debugging workbench for checking code fixes before they are applied to the original repository. |
