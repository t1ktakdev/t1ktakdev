# t1k

Делаю веб-приложения, небольшие инструменты для разработчиков и автоматизацию.

В основном работаю с Node.js, Python и вебом. Люблю превращать идеи в рабочие проекты и по ходу разбираться в технологиях, которые нужны для конкретной задачи.

## Избранные проекты

| Проект | Что делает |
| --- | --- |
| [**ReproShot**](https://github.com/t1ktakdev/ReproShot) | CLI, который превращает упавшую команду в локальный bug-report bundle с логами, состоянием Git, версиями окружения, скриптами воспроизведения и редактированием найденных секретов. [npm](https://www.npmjs.com/package/reproshot) |
| [**ReproDeck**](https://github.com/t1ktakdev/ReproDeck) | Десктопный инструмент для проверки исправлений до их применения к исходному репозиторию. |
| [**niri-pip**](https://github.com/t1ktakdev/niri-pip) | Управление Picture-in-Picture и плавающими окнами для Wayland-композитора Niri. |
