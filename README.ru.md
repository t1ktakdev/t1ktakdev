# t1k

Делаю инструменты для разработчиков, локальные MCP-агенты, сетевую диагностику, desktop-утилиты и веб-приложения.

В основном работаю с Node.js, TypeScript, Python, Rust и веб-стеком. Люблю превращать идеи в рабочие проекты и по ходу разбираться в технологиях, которые нужны конкретной задаче.

## Избранные проекты

| Проект | Что делает |
| --- | --- |
| [**ForgeBridge**](https://github.com/t1ktakdev/ForgeBridge) | Локальный permissioned MCP-агент для компьютеров, которыми пользователь явно разрешил управлять. Семантические инструменты для проектов, файлов, Git, терминала, jobs, браузера, аудита, approvals и Secure MCP Tunnel. [npm](https://www.npmjs.com/package/forgebridge) |
| [**RouteWitness**](https://github.com/t1ktakdev/RouteWitness) | Локальный регистратор сетевых инцидентов для кратковременных проблем с подключением. Собирает ограниченные доказательства до, во время и после сбоя и формирует офлайн-отчёты. [v0.1.0](https://github.com/t1ktakdev/RouteWitness/releases/tag/v0.1.0) |
| [**ReproShot**](https://github.com/t1ktakdev/ReproShot) | CLI, который превращает упавшую команду в локальный bug-report bundle с логами, состоянием Git, данными окружения, шагами воспроизведения и редактированием секретов. [npm](https://www.npmjs.com/package/reproshot) |
| [**ReproDeck**](https://github.com/t1ktakdev/ReproDeck) | Desktop-инструмент для проверки исправлений до их применения к исходному репозиторию. |
| [**niri-pip**](https://github.com/t1ktakdev/niri-pip) | Управление Picture-in-Picture и плавающими окнами для Wayland-композитора Niri. |
